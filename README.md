CS1121 Problem 4: A Coney Conundrum

Prints the full menu for Bratty Buns Hot Dog Stand. Every dog comes in a bun at a base price of $0.99 and can have any combination of seven toppings (ketchup, mustard, chopped onions, tomato wedge, sweet relish, sport peppers, sauerkraut), including none. The program lists all 128 combinations with their prices, using a Yes/No (1/0) choice for each topping to generate them.

Requirements
Java Development Kit (JDK) 8 or newer
A terminal
Git (to clone the repository)
Usage

Compile the program with the following command:

javac HotDog.java

Run the program with the following command:

java -ea HotDog

The -ea flag enables the assertion that checks the program printed exactly 128 combinations.
